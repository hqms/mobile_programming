# Mobile Programming

This repository is intended as suplementary coding material for Mobile Programming lecture. 
Every subject will tag in some commits, and every commit reflect the sub-subject on the slides.

This repo will always update with the latest slides. Always pull the latest changes and re-sync the Gradle

To run this project:
1. Open this repository in Android Studio.
2. Sync the project with Gradle files (**File > Sync Project with Gradle Files**).
3. Set up and launch an Android Emulator (API 24 or higher) or connect a physical Android device.
4. Select the `app` configuration and click **Run** (or press `Shift + F10`), or run `./gradlew installDebug` from the terminal.
